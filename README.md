# Roblox 脚本合集

> 一个由 Baiyan 编写的 Roblox 实用脚本集合，包含多种功能模组。

---

## 📦 脚本列表

| 脚本名称 | 功能描述 |
|----------|----------|
| `FlyGuiV3` | 飞行功能 GUI 界面 |
| `NameVip` | VIP 名称显示相关 |
| `aim` | 瞄准辅助功能 |
| `fakegamepass` | 伪造游戏通行证 |
| `fps` | FPS 解锁/优化工具 |
| `gamepass` | 游戏通行证相关功能 |
| `gamepassmenu` | 游戏通行证菜单界面 |
| `godmod` | 无敌/上帝模式 |
| `jump` | 跳跃增强 |
| `mm2` | Murder Mystery 2 相关脚本 |
| `mod1` / `mod2` | 独立模组功能 |
| `modall` | 全功能模组整合 |
| `sab-modded` | 改装版 Saber 相关 |
| `script` | 动作/动画脚本（支持 R15 角色）[reference:0] |
| `speed` | 速度调节 UI（支持手动输入数值）[reference:1] |
| `tp-script` | 传送功能脚本 |

---

## 🚀 使用方法

1. 将所需脚本的源代码复制到剪贴板
2. 在 Roblox 游戏中使用脚本执行器（如 Synapse X、Krnl 等）粘贴并运行
3. 按照脚本界面提示进行操作

> ⚠️ 部分脚本（如 `script`）需要在 **R15 角色** 下使用，使用前建议先点击“重生”以避免动画错误[reference:2]。
