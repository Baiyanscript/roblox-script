## 📖 项目简介 (About)

这是一个 Roblox Lua 脚本的集合仓库，汇集了多种用于增强或修改游戏体验的脚本。所有脚本均由 `Baiyanscript` 维护和更新[reference:7]。

## 🚀 如何使用 (How to Use)

1.  **获取脚本**: 克隆本仓库或直接下载所需的 `.lua` 脚本文件。
2.  **准备执行器**: 你需要一个 Roblox 脚本执行器 (如 Synapse X, Krnl 等)[reference:34]。
3.  **执行脚本**: 打开 Roblox 游戏，将脚本内容复制到执行器中，或通过执行器的加载功能运行脚本文件。
